# Sanjida Rahman — Personal Website using Hugo

A responsive personal portfolio built with Hugo and deployed with GitHub Pages.

## Run locally
Install Hugo Extended and Git, open this folder in a terminal, then run `hugo server`.
Open the local URL shown by Hugo, usually http://localhost:1313/.

## Personalize before publishing
1. In `hugo.toml`, replace `YOUR-USERNAME` with your GitHub username.
2. In `content/projects.md`, replace the placeholder Figma, live site, repository, and publication links.
3. In `content/contact.md`, add only the email and public profile links you want to share.
4. Review all project and publication descriptions for accuracy.

## Publish on GitHub Pages
1. Create a GitHub repository named `personal-website-hugo`.
2. Upload/commit the files to the `main` branch.
3. In repository Settings → Pages, choose **GitHub Actions** as the source.
4. Open the Actions tab and wait for the Hugo deployment workflow to succeed.
5. Open the live URL shown by GitHub Pages.
